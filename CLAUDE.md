# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository layout

This is a multi-part web app starter kit with three top-level directories:

- `my-app/` — Next.js 16 frontend (React 19, TypeScript, Tailwind CSS v4). This is the only part currently under git version control (its own `.git`).
- `api/` — ASP.NET Core Web API targeting **.NET 10** (`api/api/`, solution file `api/api.slnx`). Scaffolded from the default template (WeatherForecast controller + OpenAPI).
- `db/` — placeholder, currently empty.

The frontend and backend are independent projects with no wired-up integration yet; each runs on its own.

## Frontend (`my-app/`)

All npm commands run from `my-app/`.

```bash
npm run dev     # start dev server (Turbopack) at http://localhost:3000
npm run build   # production build
npm run start   # serve the production build
npm run lint    # ESLint (flat config, eslint-config-next core-web-vitals + typescript)
```

There is no test runner configured.

Architecture notes:
- App Router (`app/` directory): `layout.tsx` is the root layout, `page.tsx` the home route, `globals.css` holds Tailwind styles.
- `@/*` path alias maps to the `my-app/` root (see `tsconfig.json`).
- Tailwind v4 is wired through Turbopack via a loader rule in `next.config.ts` (not a PostCSS config).
- `next.config.ts` enables several newer Next.js features: `cacheComponents`, `partialPrefetching`, and `experimental.agentFeedback`. Be aware these affect caching/prefetch behavior when debugging rendering.

**Important — this is Next.js 16, not earlier versions.** `my-app/AGENTS.md` warns that APIs, conventions, and file structure differ from older Next.js. Before writing frontend code, consult the bundled docs in `my-app/node_modules/next/dist/docs/` rather than relying on prior Next.js knowledge. The `<!-- nextjs-agent-rules -->` block in `AGENTS.md` is regenerated by `next dev`; commit it alongside your changes to keep the tree clean rather than reverting it.

## Backend (`api/`)

Run from `api/api/` (or point `--project` at it). Requires the .NET 10 SDK.

```bash
dotnet run                    # run the API (http profile → http://localhost:5055)
dotnet run --launch-profile https   # https → https://localhost:7211
dotnet build                  # build
```

- Controller-based Web API (`Controllers/`), OpenAPI document mapped at `/openapi` in Development only (`Program.cs`).
- Nullable reference types and implicit usings are enabled (`api.csproj`).
